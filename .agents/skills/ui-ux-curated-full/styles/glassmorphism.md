# Restrained Glassmorphism

Use for elevated navigation, side panels, command bars, overlays, compact summary cards, and premium shells. The base canvas should remain mostly solid.

Recipe: translucent surface + modest backdrop blur + subtle 1px border + restrained shadow. Maintain strong foreground contrast. Use one glass elevation level for normal floating surfaces and one stronger level for modals; avoid unique recipes per component.

Do not place long forms, dense tables, or paragraphs on highly transparent glass. Avoid stacking multiple translucent panels where backgrounds visually collide.
