# Assistant / Chat UI

Chat should be an intent surface, not the entire product. Keep conversation compact and augment it with structured artifacts: plans, diffs, evidence, approvals, status, and suggested next actions. Distinguish user input, agent action, tool evidence, and system status visually.

Use inline contextual actions near the relevant message/artifact. Avoid long assistant monologues when a compact card or delta view communicates state better. Mobile: prioritize composer, current task state, and one contextual panel at a time.
