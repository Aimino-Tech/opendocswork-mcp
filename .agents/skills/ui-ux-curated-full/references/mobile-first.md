# Mobile-first Product UX

On mobile, one task per viewport. Use bottom sheets for contextual detail/actions, sticky primary actions when appropriate, and bottom navigation only for top-level destinations. Avoid desktop sidebars collapsed into tiny icon rails if the information model does not fit.

Keep the most important status and next action above the fold. Forms should use appropriate input modes and autofill. Modals should usually become full-height sheets/pages on small screens. Support safe areas and one-handed reach for frequent actions.
