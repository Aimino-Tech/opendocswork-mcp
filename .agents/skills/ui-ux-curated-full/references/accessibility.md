# Accessibility

Target WCAG AA behavior. Body text and essential iconography need sufficient contrast. All functionality must be keyboard reachable with a visible focus indicator. Interactive icon-only controls require accessible names. Do not encode state or severity only by color.

Forms need persistent labels, clear field-level errors, a programmatic relationship between errors and inputs, and sensible focus after submit. Dialogs trap focus while open and return focus to the invoking control. Respect reduced-motion preferences and browser zoom/text scaling. Touch targets should generally be at least ~44px where mobile/touch use is expected.
