# Dashboard Patterns

Lead with current state and exceptions, not vanity metrics. Put actionable blockers/alerts above historical summaries. Metrics need context (period, comparison, unit) and should not dominate if the user primarily needs to act.

Use persistent filters when they change the whole surface, local filters near the region they affect, and visible filter state. Dense tables can use sticky headers, compact rows, column prioritization, and row-level actions revealed on focus/hover without hiding essential actions from touch users.
