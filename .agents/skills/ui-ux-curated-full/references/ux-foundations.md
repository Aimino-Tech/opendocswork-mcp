# UX Foundations

Prioritize task completion over decoration. A screen needs one obvious primary purpose, one dominant action, and a stable visual hierarchy. Group by user intent rather than backend entities. Keep related controls near the content they affect. Prefer progressive disclosure over exposing every option at once.

Use a small spacing scale consistently. Dense work surfaces can be compact, but interactive controls still need comfortable targets. Preserve alignment across sibling panels. Avoid unnecessary card nesting; whitespace, dividers, background changes, and typography often provide enough grouping.

Every async action needs an immediate state: idle, hover/focus, pending, success, error, disabled where applicable. Preserve user input through recoverable errors. Destructive actions need clear consequence language and an undo path when feasible.
