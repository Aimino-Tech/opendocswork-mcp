# Typography

Use a restrained hierarchy: display/hero only where marketing or onboarding genuinely needs it; work apps typically need page title, section title, body, label, metadata/code. Keep body text around 14–16px depending on density, with comfortable line-height. Long-form text should not span the full viewport.

Use tabular numerals for changing metrics and aligned numbers. Use monospace only for code, IDs, logs, and technical values. Avoid ultra-light text on translucent surfaces.
