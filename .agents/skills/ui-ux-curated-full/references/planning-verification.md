# Planning and Verification UI

Planning views should make assumptions, missing evidence, dependencies, acceptance criteria, and open decisions visible. Verification views should map each criterion to evidence and a pass/fail/unknown state. Unknown is not pass.

Use progressive disclosure for raw logs. Show the smallest evidence needed to trust the verdict, with an explicit path to inspect source detail. Highlight plan deviations and unexpected changed files/components. Keep READY / FIX LOCAL / REPLAN / HUMAN DECISION visually distinct.
