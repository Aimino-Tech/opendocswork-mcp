# Anti-Generic AI UI

Avoid: default purple-to-pink gradients, glowing borders everywhere, excessive glass cards, rounded pills for every control, giant centered copy in operational screens, meaningless sparkle icons, vague labels like “Magic”, uniform card grids regardless of information type, and animated blobs behind text.

Prefer: product-specific hierarchy, grounded data density, clear status language, distinctive but restrained typography, purposeful asymmetry, and one memorable visual motif rather than ten effects.
