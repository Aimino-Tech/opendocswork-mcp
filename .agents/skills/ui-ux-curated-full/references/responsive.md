# Responsive Layout

Design from the narrowest meaningful state upward. Decide what collapses, wraps, scrolls, becomes a drawer/sheet, or disappears. Do not merely shrink desktop UI.

For work apps: on small screens keep the primary task, current status, and next action visible; move secondary metadata/actions behind a detail sheet or overflow menu. Tables should become priority-column lists/cards rather than horizontal-scroll prisons when practical. Test 375, 768, 1024, and 1440px widths plus long text and localization.
